# ☕ Cafe Management System

## 📌 About the Project

The Cafe Management System is a Java-based desktop application developed using Java Swing. It helps manage cafe orders, calculate bills, and display order details through a simple graphical user interface (GUI).

This project is designed to demonstrate Java programming concepts, GUI development, event handling, and basic billing operations. It is suitable for beginners who want to improve their Java programming skills through a practical mini project.

## 🎯 Objectives

- To develop a simple and user-friendly cafe management application.
- To display food and beverage items with their prices.
- To manage customer orders and quantities.
- To calculate the subtotal, tax, and final bill automatically.
- To generate a readable bill receipt.
- To understand Java Swing and event-driven programming.

## ✨ Features

### 🍔 Food and Beverage Menu
- Coffee
- Tea
- Sandwich
- Burger
- Pizza
- French Fries
- Cold Coffee
- Juice

### 🛒 Order Management
- Select items from the menu.
- Enter the required quantity.
- Add multiple items to the cart.
- Increase the quantity when the same item is added again.
- Remove selected items from the cart.
- Clear the entire cart when required.

### 💰 Billing System
- Automatically calculates item prices.
- Calculates the subtotal.
- Adds a sample tax of 5%.
- Displays the final payable amount.
- Generates a bill receipt containing order details.

### 🖥️ Graphical User Interface
- Built using Java Swing.
- Includes buttons, labels, a combo box, and a table.
- Displays cart details in an organized format.
- Provides messages for invalid inputs and checkout actions.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **Layout Management:** AWT Layout Managers
- **Table Management:** JTable and DefaultTableModel
- **Development Environment:** Visual Studio Code
- **Version Control:** Git and GitHub

## 💻 System Requirements

- Windows, Linux, or macOS
- Java Development Kit (JDK)
- Visual Studio Code or another Java-compatible IDE
- Java source file: `CafeManagementSystem.java`
